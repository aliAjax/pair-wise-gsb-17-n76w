# hxwl-03 岩土钻孔编录

钻孔分层、标贯与地下水位的现场记录工作台，供现场编录员连续录入多口钻孔。

## 技术栈

React + Vite + TypeScript + CSS（无后端，记录保存在浏览器本机）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 功能

### 连续编录

- 多口钻孔管理：新增 / 编辑 / 删除 / 切换钻孔，左侧列表显示孔深、层数、水位
- 分层按深度从浅到深排列；层顶深度恒等于上一层底（首层顶为 0），新增分层时自动接续，只需填层底
- 中间分层删除后，后续分层自动前移，始终保持首尾相接、无缺口
- 标贯按分层录入（每分层一条），可新增、修改、删除

### 孔段约束与字段校验

错误精确提示到具体字段，而非笼统报错：

- 钻孔编号必填且全库唯一；孔深须为正数
- 层底必须大于本层顶（上一层底）、不得越过下一层顶、不得超过孔深
- 标贯点深度必须落在所属分层孔段内，击数须为正整数
- 地下水位埋深不得超过孔深
- 修改孔深后，已有分层/水位超出孔段会在页面上持续标注异常，直到修正

### 岩性筛选与看板联动

- 筛选关键字：黏土、粉砂、卵石、强风化（分类名或描述中命中即归入该类，可多选取并集）
- 看板四项数字随筛选结果变化：累计进尺（命中分层厚度合计）、地层数量、最高标贯、地下水位范围
- 未命中筛选的分层在表中置灰保留，便于对照；含异常标贯的行单独标红提示

### 本机持久化

- 全部记录、当前选中钻孔、筛选状态保存在浏览器 localStorage
- 关掉页面再打开，自动恢复上次的孔、分层与筛选；首次打开预置 ZK-18 / ZK-21 / ZK-24 三口示例孔

## 代码结构

- `src/types.ts`：领域模型（钻孔 / 分层 / 标贯）
- `src/domain.ts`：深度推导、字段校验、筛选与看板指标、示例数据
- `src/storage.ts`：localStorage 读写
- `src/components.tsx`：钻孔弹窗、分层行内表单、标贯表单
- `src/App.tsx`：孔列表、分层表、筛选与看板联动
