# hxwl-03 岩土钻孔编录

面向现场编录员的钻孔分层、标贯与地下水位连续记录工作台。

## 技术栈

React 19 + Vite + TypeScript + CSS，数据存储使用浏览器 localStorage（无需后端）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 功能

- **钻孔工作台**：左侧钻孔列表（新增 / 编辑 / 删除），右侧当前孔的分层记录，可连续录入多口孔。
- **分层接续**：分层按深度从浅到深排列；新增分层的层顶自动定位到第一个缺口（默认接上上一层底），层底不得进入下一层或超过孔深；删除中间分层后可原位回填。
- **标贯与水位校核**：标贯点深度必须落在该层层段 `[层顶, 层底]` 内，击数为正整数且与深度成对填写；地下水位埋深不得超过孔深，并在所属分层卡片上标注。
- **岩性筛选**：黏土、粉质黏土、粉砂、卵石等 8 个分类可多选；看板四项数字（命中钻孔、命中地层、最高标贯、平均水位）随筛选实时变化，分层列表按命中过滤。
- **字段级报错**：编号重复、孔深非数字或小于已录分层、层顶未接续、标贯出段等问题直接标红具体字段并给出修正值。
- **本机持久化**：全部记录写入 `localStorage`，关闭页面或刷新后重新打开，孔与分层仍在；首次打开带 ZK-18、ZK-21 两口示例孔。

## 代码结构

- `src/types.ts` — 钻孔 / 分层领域模型
- `src/domain.ts` — 深度接续、缺口定位、表单校验、localStorage 存取、示例数据
- `src/components/HoleForm.tsx` — 钻孔新增 / 编辑表单
- `src/components/LayerForm.tsx` — 分层新增 / 编辑表单
- `src/App.tsx` — 工作台布局、筛选、看板与持久化编排
